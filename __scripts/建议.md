### 2.1 B1 — 工具 schema

`zodToJsonSchema.ts` 仍是 `toJSONSchema(schema)` 原样返回，没有 `hoistObjectTypeForUnionBranches`。Anthropic 对 union 工具 schema 的拒绝条件还在。整文件取。

### 2.2 B5 — 飞书 post

`extract-payload.ts` 第 72 行仍是：

```ts
const nodes = (parsed.zh_cn?.content ?? parsed.en_us?.content ?? []) as any[]
```

单语言 `{ title, content }` 仍会被当成空正文。移植树只多了 `parsed.content` 和一条测试。整文件取。`adapters/feishu/index.ts` 不要动。

### 2.3 B4 — absolute-URI HTTPS

`systemProxyBridge.ts` 第 141–144 行仍是：协议不是 `http:` 就 400，并写 `HTTPS proxy requests must use CONNECT`。

清单第 2 节「把 `transport: http` 换成按目标协议选的 transport」是错的，会把 TLS 交到明文代理。移植树 `68449cfec` 起的做法才对：

- absolute-URI 的 https 走 `forwardAbsoluteUriHttps`
- http/https 代理规则先 `CONNECT`，再在隧道上用 `TlsOverSocketAgent` 做 TLS
- SOCKS 套接字上做 TLS，不再把 `http.Agent` 交给 `https.request`
- 读握手响应之间 `pause()`，避免丢包
- IPv6 字面量不当作 SNI

这三处文件（实现、测试、两个 pem）和 `.gitignore` 的夹具白名单一起取。`#1895` 的 proxy bypass 改的是 `src/utils/proxy.ts` 和 `networkSettings.ts`，没有改这个 Electron 桥，不冲突。

### 2.4 B6 — Windows 安装器防火墙

### 2.6 A3 — 隧道地址进 H5 白名单
